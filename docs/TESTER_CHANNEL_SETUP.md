# Tester channel setup

Do these in order after the installer finishes. Do not invent a Configure step.

1. Setup dropdown = the real headphones or speakers you hear from. Not CABLE Input, not SonicScout2.0, not Voicemeeter.
2. Right-click the speaker icon, open Sounds, Playback.
3. SonicScout2.0 should already be 7.1 Surround. Leave it. Do not click Configure.
4. SonicScout2.0 + is the 16-channel device. Leave it at the driver default. Do not set it to 7.1 or Stereo. That caps V5 at 8 channels.
5. Double-click each SonicScout device, Spatial sound tab, set Off. Windows Sonic, Dolby, and DTS:X block the EQ.
6. Neither device muted. Volume above 0.
7. In game, match the tune:
   - BO7 V0-V4 and other 8-channel tunes: output device SonicScout2.0
   - BO7 V5: output device SonicScout2.0 +
   - Call of Duty: Speaker Output = Windows Default, Enhanced Headphone Mode off
   - Battlefield 6: Speaker Output = 7.1 Surround
8. Main app: SCOUTPASS must say running, not STOPPED.
